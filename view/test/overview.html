geomlib — view/test/ catalog

Manual catalog of the demo + fixture pages. Each demo loads ../../dist/bundle.js — run npm run bundle first, then open a page. Slideshow demos: press p to present, → to advance.

Hand-maintained — add a row here when you add a top-level demo. The per-construction subdirectories double as snapshot-test input (tests/SnapshotTest.ts), so they're listed as groups rather than individually.
