These are Dr. Joyce's original 1996 pages, kept verbatim as snapshot-test input. They cannot load on their own in a modern browser for three separate reasons: (1) each figure is a Java <applet>; (2) navigator.javaEnabled() was removed from browsers, so the page's own .gif fallback never swaps in either; (3) ../elements.js (Joyce's nav chrome) was never mirrored into this repo — only the HTML and its .gifs were, since that is all the snapshot parser needs. This viewer reads a page without modifying it, and rebuilds each applet as a geomlib canvas from that applet's own <param> tags.
