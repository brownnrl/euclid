CSS named-color swatches (#125)

Every name parseColor accepts from the W3C/CSS set (0.13.0+), drawn as a filled square with its name labelled at the upper-left vertex. Names lookup case-insensitively; grey-spelling aliases (not shown) mirror their gray twins. The five crimson labels — green, orange, pink, darkgray, lightgray — keep their historical Java AWT values, which differ from CSS (e.g. this green is 0,255,0, not CSS's 0,128,0; this darkgray is the darker 64,64,64). Each swatch is a polygon;quadrilateral whose faceColor is just the name string.
