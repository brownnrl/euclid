CSS functional colours, and a typo that says so (#179)

parseColor took colour names, hex and H,S,B triples; anything else — including rgb() / rgba() — fell through to transparent, in silence. Now the functional forms pass straight through to the canvas, and a string nothing recognises is reported (badge, console, geomlib.diagnostics()) while still drawing transparent.

Left triangle: rgb(120,180,210). Middle: rgba(210,150,120,0.5) drawn over a black segment — the segment shows through, which is the alpha working. Right: faceColor: "lighgtblue", a typo — the face is transparent as before, but the badge in the corner now says why. Press p to see a face fade (outlineAndFill) compose with the rgba alpha rather than fight it.
