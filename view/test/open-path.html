Open path / polyline (#121) — Heron's bent line

The I.20 Guide (Heron's minimum-distance problem) talks about the path AEB — the bent line A→E→B that bounces off the mirror line CD at E. polygon;path;A,E,B is an open polyline: a connected route through the listed points that does not close back to A (unlike a polygon). It is one highlightable element, so hovering the prose ref lights the whole route.
