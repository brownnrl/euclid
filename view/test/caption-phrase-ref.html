Multi-word caption display refs (#136)

Press p and step through. Each caption hovers a different token form — watch which part of the sentence lights up and which element it highlights.

  • {AB} — the element name is also the display.
  • {ABC|angA} — single-word override: renders "ABC", binds the angle marker rather than the triangle that owns the name.
  • {the side from A to C|AC} — the phrase form. Before #136 this did not match and the caption showed the raw {…|…} text; the workaround was to bind one keyword (the {side|AC} from A to C), lighting only that word.
