bidirectional highlight binding (#108)

Hover a reference below for a transient preview; click to pin it so it stays highlighted (click again to unpin). Either sets the canvas element's emphasis (text→diagram). The library then emits a geomlib:highlight event carrying the element's canonical name + aliases, and the page lights up every reference to the same element — including ones spelled with an alias (diagram→all-text). Never triggered by clicking the canvas.

Points: the apex A and the base corner B. The base segment AB (also written BA). The circle BCD — Euclid also names it CDB and DBC.
