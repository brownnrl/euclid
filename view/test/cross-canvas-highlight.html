Cross-canvas highlight (#130) — I.26 two cases

A proposition drawn as two figures (here the ASA and AAS cases of I.26) shares labels: both triangles are ABC. A single prose reference should light the element in both canvases at once. geomlib.highlightByName("ABC", on, {canvasids:[…]}) sets emphasized on every matching element across the listed canvases and fires each one's geomlib:highlight event — alias-aware, so a ref spelled "CBA" still matches.

Hover triangle ABC — it lights in both cases.
